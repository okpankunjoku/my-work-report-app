# ClockIn Pro – Workforce Productivity & Daily Reporting System

ClockIn Pro is a full-stack workforce management and productivity tracking application built with **React.js, Node.js, Express.js, and MongoDB**.

The application helps organizations manage employees, track attendance, record daily work reports, monitor productivity, and keep employees and administrators informed through in-app and email notifications.

## 🚀 Key Features

* 🔐 **Authentication & Authorization** – Secure employee login with role-based access for Employees and Administrators.
* ⏰ **Attendance Management** – Clock in and clock out, track working hours, and maintain daily attendance records.
* 📝 **Daily Work Reports** – Employees can submit daily reports describing completed tasks and work activities.
* 👥 **Employee Management** – Administrators can view, search, edit, activate, suspend, and delete employee accounts.
* 📊 **Admin Dashboard** – Provides an overview of employees, attendance, reports, and workforce activity.
* 🔔 **In-App Notifications** – Employees and administrators receive notifications for important system activities.
* 📧 **Email Notifications** – Automated email notifications for events such as attendance and report activities.
* 🔎 **Search & Filtering** – Easily find employees, attendance records, and reports.
* ☁️ **MongoDB Database** – Persistent storage for employees, attendance, reports, notifications, and application data.
* 🌐 **RESTful API** – Backend API architecture for communication between the React frontend and Node.js backend.
* 📱 **Responsive Interface** – Designed to provide a clean experience across different screen sizes.

## 🏗️ Project Architecture

The project is divided into two main applications:

```text
work-report-app/
├── frontend/
│   └── React + Vite
│
└── backend/
    ├── controllers/
    ├── middlewares/
    ├── models/
    ├── routes/
    ├── services/
    ├── validations/
    └── config/
```

This separation makes the application easier to maintain, develop, test, and scale.
